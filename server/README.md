# Серверная часть Astra (svcode.ru)

Приложение оффлайн-первое: расчёты, журнал и карты живут на телефоне и никуда не
уезжают. Сервер нужен только «Сообществу» — обсуждениям, входу и картам, которые
клиенты присылают астрологу.

Что крутится на `80.78.245.171`:

| служба | порт | что делает |
|---|---|---|
| `postgresql` | — | база `astra`: обсуждения, профили, карты клиентов, RLS |
| `gotrue-astra` | 9998 | вход: почта + пароль, восстановление по коду |
| `postgrest-astra` | 3001 | данные по HTTP, права режет RLS |
| `astra-mailhook` | 9910 | отправка писем входа (этот каталог) |
| `astra-purge-charts.timer` | — | раз в сутки чистит разобранные карты клиентов старше 90 дней |

Наружу торчит только nginx: `astra.svcode.ru/auth/v1` и `/rest/v1`.

## Почему письма шлёт отдельная служба

GoTrue умеет слать письма сам, но только по SMTP, а reg.ru режет исходящие
25/587/465 на все хосты — обычный SMTP с этого сервера невозможен. HTTPS открыт,
и у российских почтовых сервисов есть HTTP-API, поэтому письмо уходит через хук
`send_email`: GoTrue отдаёт письмо `mailhook.py`, тот шлёт его по API.

Зарубежные сервисы (Mailgun, SendGrid) с этого хоста как раз доступны, но адрес
человека — персональные данные, и слать их за границу значит вернуть ровно то,
от чего мы уезжали (152-ФЗ ст. 12). Поэтому только российский сервис.

В письме **код из шести цифр**, а не ссылка: приложение на телефоне живёт по
адресу `https://localhost` и возврат по ссылке поймать не может, а код человек
просто перепечатывает — веб и APK ведут себя одинаково.

## Что осталось сделать руками (нужен доступ владелицы)

Пока не сделано — письма не уходят, а только пишутся в журнал службы
(`journalctl -u astra-mailhook`), то есть код видит лишь администратор.

1. **Завести аккаунт в Unisender Go** (российский, данные в РФ, бесплатно до
   ~6000 писем в месяц — нам нужны десятки). Взять там ключ API.
2. **Подтвердить домен `svcode.ru`**: сервис выдаст записи DKIM и SPF, их надо
   добавить в DNS домена (панель reg.ru). Сейчас у домена нет ни MX, ни TXT —
   без этих записей письма будут падать в спам или отбиваться.
3. Вписать ключ на сервере и перезапустить службу:
   ```
   nano /etc/astra-mailhook.env      # MAIL_API_KEY=…
   systemctl restart astra-mailhook
   ```
4. Проверить: в приложении «Забыл пароль» → код должен прийти на почту.

Сменить сервис — правка одного `API_URL` и заголовка ключа в `mailhook.py`;
у mailopost.ru, smtp.bz и notisend.ru API такие же по устройству, все они с
этого сервера доступны (проверено).
