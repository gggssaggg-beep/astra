# astra-engine — расчётное ядро Astra на Java

Западная школа: положения объектов, знаки и градусы, дома, аспекты как
интервалы (вход в орбис → точный момент → выход). **Джйотиша здесь нет** —
это отдельная очередь, решение владелицы 09.08.2026.

Библиотека подключается зависимостью и вызывается обычными методами — так же,
как приложение зовёт свой скрипт. Сети и сервера не требует.

📘 **[Документация по использованию — docs/USAGE.md](docs/USAGE.md)**: подключение,
все вызовы с примерами, подмена поставщика эфемерид, частые ошибки.

---

## ⚠️ Лицензия — решить ДО подключения

Swiss Ephemeris распространяется Astrodienst на условиях **AGPL** либо по
**платной коммерческой лицензии**. Java-порт наследует то же условие. Значит:

- проект, который подключит эту библиотеку, придётся выпускать под AGPL
  (то есть открыть исходники), **либо**
- купить у Astrodienst коммерческую лицензию (разовый платёж).

Наш собственный код (аспекты, зодиак, углы, порядок выдачи) этим не связан —
он принадлежит проекту. Ограничение идёт только от эфемерид.

Если ни то ни другое не подходит, есть путь с мягкой лицензией: заменить
поставщика эфемерид (LGPL-реализации VSOP87) — интерфейс `Ephemeris` для того и
существует. Ценой станут астероиды и TNO, которых в таких реализациях нет, и
повторная сверка с эталоном.

## Как устроено

Папка самодостаточна: библиотека, эталонные файлы, генератор эталона и
документация лежат здесь же — её можно отдать в другой проект целиком.

    astra-engine/
      src/main/java/…   код библиотеки
      src/test/java/…   парити-тесты против эталона
      golden/           эталонные JSON, снятые с JS-движка
      tools/golden.mjs  генератор эталона (Node, читает движок из ../app)
      docs/USAGE.md     документация по использованию
      build.gradle      сборка

    Ephemeris            интерфейс поставщика положений (§2.3 ТЗ)
      └ SwissEphemeris   реализация: Java-порт Swiss Ephemeris, режим SWIEPH
    Zodiac               знак и градус по долготе
    Angles               угловая арифметика (norm, angdiff, separation)
    Aspects              аспекты суток: интервалы, корзины, порядок
    Constants            объекты, аспекты, порядок по удалённости от Солнца

Вся логика выше `Ephemeris` от поставщика не зависит: подменяется одной
строкой, тесты остаются те же.

## Пример

```java
try (var eph = new SwissEphemeris("/path/to/ephe")) {
    var day = Aspects.aspectsOn(eph, Instant.parse("2026-08-09T00:00:00Z"));
    for (var a : day.fast()) {
        System.out.printf("%s %s %s — точно в %s, орбис %.2f°%n",
                a.p1(), a.symbol(), a.p2(), a.exactTime(), a.exactOrb());
    }
    var pos = eph.positions(Instant.now(), List.of("Солнце", "Луна"));
    pos.forEach(p -> System.out.println(p.name() + " — " + Zodiac.format(p.lon())));
}
```

## Золотые файлы: чем доказывается, что порт верен

В `golden/` лежат JSON, снятые с работающего JS-движка Astra
(`node astra-engine/tools/golden.mjs`): юлианские даты, положения, знаки, дома во всех
системах, аспекты суток с интервалами, события неба, ретро-станции, поиск
аспектов и градусов, фигуры. Набор намеренно недобрый: южное полушарие,
заполярье, экватор, нулевой меридиан, високосный день, сутки затмения, момент
у станции планеты и граница знака.

Java-тесты читают те же файлы и сверяют числа. Допуски:

| что | допуск | почему столько |
|---|---|---|
| долготы, куспиды | 1e-6 ° | это тот же код Swiss Ephemeris; расхождение может дать только арифметика double |
| юлианские даты | 1e-9 сут | ошибка здесь сдвигает всё остальное |
| моменты времени | ±1 с | обе стороны ищут корень делением пополам, последний бит может отличаться |
| орбис | 0.011 ° | в самом JS он округлён до сотых |

Если каталога эфемерид нет, тесты движка **пропускаются**, а не проходят молча:
без файлов SWIEPH сверять нечего.

## Сборка

```bash
cd astra-engine
gradle test          # прогон парити против золотых файлов
gradle build         # jar + sources jar
```

Эфемериды и золотые файлы находятся автоматически (пути заданы в `build.gradle`:
`../ephe` и `./golden`).

## Что ещё не перенесено

События неба (ингрессии, лунации, затмения), ретро-фазы, поиск аспектов и
градусов на отрезке, фигуры дня — золотые файлы для них уже сняты
(`events.json`, `stations.json`, `retrophase.json`, `occurrences.json`,
`degrees.json`, `figures.json`), сам перенос идёт следующими партиями.
