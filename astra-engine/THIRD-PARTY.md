# Сторонний код в составе библиотеки

## Swiss Ephemeris, порт на Java

**Что:** `src/main/java/de/thmac/swisseph/` — 50 файлов, около 2,4 МБ исходников.
Это не наш код и правкам не подлежит: любое изменение сделает расчёты
несравнимыми с приложением и с профессиональными программами.

**Происхождение:**

| | |
|---|---|
| исходная библиотека | Swiss Ephemeris, Astrodienst AG, Швейцария |
| авторы оригинала | Dieter Koch, Alois Treindl |
| перевод на Java | Thomas Mack (версия порта 2.01.00-01) |
| откуда взято | `https://github.com/krishnact/swisseph` |
| коммит | `6000e46cf8fc57e15444154018af176304f39ec2` |
| дата копирования | 2026-08-09 |

**Почему копия, а не зависимость.** Ни Maven Central, ни JitPack этот порт не
отдают: JitPack публикует метаданные версии `master-6000e46cf8-1`, но сами
`.pom` и `.jar` возвращает 404 — проверено прямыми запросами, из-за этого
падали первые две сборки. Копия делает папку самодостаточной: библиотека
собирается офлайн и целиком, что для оффлайн-первого проекта правильнее
внешнего репозитория, который может исчезнуть.

**Лицензия.** Swiss Ephemeris распространяется Astrodienst на условиях **AGPL**
либо по **платной коммерческой лицензии**; порт на Java наследует то же
условие, о чём прямо сказано в заголовках файлов. Следовательно:

- проект, который подключает `astra-engine`, обязан либо выпускаться под AGPL
  (с открытыми исходниками), либо иметь коммерческую лицензию Astrodienst;
- это ограничение идёт от эфемерид, а не от нашего кода: `ru.svcode.astra.*`
  (зодиак, углы, аспекты, порядок выдачи) принадлежит проекту.

Полные тексты лицензий и оговорок — в заголовках самих файлов порта и на
`https://www.astro.com/swisseph/`.

**Единственная наша правка в этих файлах — кодировка.** Семь файлов приехали в
Latin-1 (градусы и умляуты в комментариях), из-за чего javac с UTF-8 отказывался
их читать. Они перекодированы в UTF-8 побайтово, без изменения символов; логика
и числа не тронуты. Остальные 43 файла уже были UTF-8.

**Что делать при обновлении порта.** Скачать новую версию тем же способом,
заменить каталог целиком, прогнать `gradle test`: золотые файлы сразу покажут,
разошлись ли числа. Записать здесь новый коммит и дату.

## Файлы эфемерид

`../ephe/` — двоичные файлы Swiss Ephemeris (ядро и малые тела). Тоже не наш
код; распространяются Astrodienst на тех же условиях. Библиотека читает их с
диска, путь задаётся в конструкторе.
