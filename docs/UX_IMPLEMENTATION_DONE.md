## 3. Детали 7а (самое объёмное — #15)
- Подход: **opt-in классы** (шторка САМА добавляет `sheet-base`/`sheet-backdrop`
  в разметку) вместо расширения глобального `section.sheet` — иначе задело бы
  немигрированные шторки (у части не переопределены отдельные свойства → каскадный
  риск). Так переход **инкрементальный и безопасный по построению**.
- `.sheet-base` размещён ПОСЛЕ `.glass` в app.css: равная специфичность (0,1,0),
  но правило ниже в файле → его `border-radius: 22 22 0 0` побеждает
  `.glass{border-radius:var(--radius)}`, как было в scoped-стилях.
- **Backdrop-дедуп: 24/24** (все `.backdrop` были байт-идентичны, кроме z-index).
- **`.sheet-base`: 21/24.** 3 шторки осознанно оставлены с кастомным `.sheet`
  (только их backdrop глобализован), причина в комментарии каждого файла:
  - `ChartsSheet` — почти во весь экран (`max-height: calc(100dvh - safe-top)`);
  - `ChatSheet` — `display:flex; flex-direction:column` (поле ввода прижато вниз);
  - `CommunitySheet` — ДВЕ шторки (лента + подшторка профиля `.upage`), 92vh/min45vh.
- 3 «особые» приняли базу с оверрайдом одного отличия: `Journal` (max-height 88vh
  + overflow), `DataPanel` (padding-bottom 20px), `DateSheet` (width min(440px)).
- В каждой мигрированной шторке scoped `.sheet`/`.backdrop` свёрнуты до `z-index`,
  локальный `@keyframes up` удалён.

## 5. Что ОСТАЛОСЬ: 7б (#14) — отложено осознанно
**#14:** вынести общие блоки `InterpretationSheet` и `StaticInterpretationSheet`
(~85% близнецы) в подкомпоненты `ui/aspect/`: `AspectActions`, `ArchetypesBlock`,
`AspectNoteBlock`, `SimilarNotes`, `OccurrenceSearch`.

**Почему не сделано в этот проход:**
1. Это крупный рефактор с состоянием (NoteBlock/OccurrenceSearch держат локальный
   `$state`/эффекты) — риск регресса выше механической правки CSS.
2. Обработчики действий у шторок РАЗНЫЕ: `InterpretationSheet` зовёт `ondiscuss(rec)`,
   `StaticInterpretationSheet` — `onchat(seed, source)`; общий `AspectActions`
   требует аккуратного проброса, а не копипаста.
3. Аудит сам предписал делать это «по одному блоку за партию, с прогоном ОБЕИХ
   шторок» — то есть отдельными выверенными шагами, не под лимит.

**Вопрос к Fable:** подтвердить дизайн подкомпонентов (границы props/колбэков для
`AspectActions` при разной проводке двух шторок) и порядок вынесения блоков.

## 6. Уроки среды (записаны в глобальный `~/.claude/CLAUDE.md`)
- **`perl -0777 -i` на Windows+Git Bash при `autocrlf=true` переворачивает EOL
  всего файла** → diff раздувается до сотен строк (каждая строка «изменена»).
  Диагностика: `git diff --ignore-space-at-eol`. Фикс: массовые правки — только
  Edit-инструментом (сохраняет EOL), не perl/sed-слурпом.
- **Скриншоты dev-сервера headless-браузером в песочнице:** dev-сервер и puppeteer
  запускать В ОДНОЙ Bash-команде (иначе разные сетевые namespace), Chrome с
  `--no-proxy-server`, vite с `--host 127.0.0.1` (иначе слушает только IPv6 `[::1]`).
