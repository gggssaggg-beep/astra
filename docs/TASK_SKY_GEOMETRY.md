## 1. «ФИГУРЫ ДНЯ» — конфигурации аспектов ★ключевое
### (название УТВЕРЖДЕНО владелицей 2026-07-08; это задание для Fable —

Идея: не просто аспекты, а ФИГУРЫ (скрытая геометрия). В натале — классика;
изюминка владелицы — ТРАНЗИТЫ: фигура, собирающаяся из транзитных аспектов
(или транзит, ЗАМЫКАЮЩИЙ натальную заготовку — напр. транзитная планета к
натальной оппозиции = Тау-квадрат), выделяется как многоплановое событие —
«динамика и вау-обстоятельства».

### Реестр фигур владелицы (список получен 2026-07-08)
Мажорные аспекты, орбисы движка. Порядок реестра, ДЕТЕКЦИИ и ОПИСАНИЙ —
строго от простых к сложносоставным (правило владелицы).

Простые (3 планеты):
1. **Большой тригон** — 3×△.
2. **Тау-квадрат** (она же называет «бумеранг») — 1×☍ + 2×□; вершина —
   планета в двух квадратах.
3. **Бисекстиль** — 2×⚹ + 1×△; вершина — планета в двух секстилях.

Составные (4+ планет; ⚠ где состав рёбер не подтверждён — уточнить у
владелицы ДО реализации, отмечено «?»):
4. **Большой крест** — 4 планеты: 2×☍ + 4×□ (содержит 4 тау-квадрата).
5. **Повозка (прямоугольник)** — 4 планеты: **2×☍ + 2×△ + 2×⚹** (состав дан
   владелицей явно; мистический прямоугольник; содержит бисекстили).
6. **Парус** — ? предположительно большой тригон + 4-я планета (⚹ к двум
   вершинам); содержит большой тригон и бисекстиль. Состав подтвердить.
7. **Косой парус** — ? вариант паруса; состав подтвердить.
8. **Трапеция** — 4 планеты, ? состав подтвердить.
9. **Конверт (пентаграмма, «гармоничный пятиугольник»)** — 5 планет, ?
   предположительно кольцо гармоничных аспектов + хорды; состав подтвердить.
10. **Щит Давида (гексаграмма)** — 6 планет: 2 больших тригона в противофазе
    + 6×⚹ (+3×☍ диагонали — подтвердить); содержит 2 больших тригона,
    бисекстили, повозки.
11. **Бриллиант** — определение владелицы: «совмещение с одной стороны
    трапеции, а с другой — тау-квадрата» (общие рёбра/планеты — схему
    подтвердить эскизом).

### Логика композиции (требование владелицы)
- Некоторые фигуры СОДЕРЖАТ другие — реестр хранит поле `contains:
  [имена под-фигур]`; детекция идёт снизу вверх: сначала все простые
  (3-планетные), затем составные СОБИРАЮТСЯ из найденных простых + недостающих
  рёбер (не переискивать с нуля — дёшево и даёт готовую декомпозицию).
- Выдача: показывается САМАЯ КРУПНАЯ фигура, её под-фигуры не дублируются
  отдельными карточками, а раскрываются внутри («состоит из: большой тригон
  Луна-Венера-Юпитер + …»).
- Трактовка фигуры строится от простого к сложному: сначала смысл под-фигур,
  затем что даёт их совмещение (тексты — отдельный контент-блок агентами,
  как раунд 28).

### Архитектура (ложится на существующий движок идеально)
- Фигура = набор рёбер-аспектов. Аспект в приложении — ИНТЕРВАЛ, значит
  **окно жизни фигуры = пересечение интервалов всех её рёбер** (вход
  последнего ребра → выход первого). Философия «аспект-окно» сохраняется.
- Реестр data-driven (как ASPECTS): { имя, арность, мультимножество рёбер,
  роль вершин, contains }. Валидация реестра тестом: у каждой фигуры число
  рёбер = C(арность,2) минус разрешённые «пустые» пары (пары без аспекта —
  часть определения, тоже в реестре).
- Поиск: сначала 3-планетные по маске (C(11,3)=165), составные — сборкой из
  простых; режимы: натал (снимок static.ts), транзит×транзит (день),
  смешанный транзит×натал в картах (транзит ДОСТРАИВАЕТ натальную заготовку —
  самый «вау»-режим, приоритет).
- UI «Фигуры дня»: полигон фигуры в колесе (подсветка всех рёбер разом,
  выделение по правилу «сам элемент, не рамка»), карточка с окном
  сборки-распада и декомпозицией; опц. уведомление «сегодня собирается …».
- Этапность реализации: (а) реестр+детекция натала с тестами на синтетических
  картах → (б) транзитные окна → (в) смешанный режим → (г) UI → (д) тексты.

## 2. Цепочки диспозиторов (формула — готова)

Формула детерминированная, ИИ для построения НЕ нужен (нужен только для
трактовки): **каждая планета → управитель знака, в котором она стоит**
(система владелицы = `SIGN_RULER` в `dispositorLore.ts`), повторять, пока не
придём к планете в СВОЁМ знаке (финальный диспозитор, «царь цепочки») или к
циклу взаимной рецепции (соправители). Солнце/Луна/Раху/Кету ничем не
управляют → они всегда истоки стрелок, в них никто не «впадает»; в графе
максимум 6 узлов-управителей (Марс, Венера, Меркурий, Юпитер, Сатурн, Уран).
- Расчёт тривиален по natal-позициям; визуализация — цепочка глифов
  «X → Y → Z ⟲» или дерево.
- Трактовка композиционная: ребро «архетип X служит архетипу Y (бога знака)»,
  финал — «вся карта стекается к Z». Промт для ИИ-чата: перечислить цепочку
  богами + попросить бытовой разбор «кто на кого работает».

## 5. Поиск планеты в градусе («Венера в 27°56′ Льва, 2020–2030»)

Возможно, и точно: целевая долгота = знак×30 + градус + минуты; сканер шагает
по эфемеридам и уточняет корень (та же техника root-finding, что для точных
аспектов). Планета может проходить точку 1 или 3 раза за цикл (директ-ретро-
директ) — выдаём ВСЕ прохождения с датой и временем в поясе пользователя.
Диапазон лет любой в пределах файлов эфемерид. UI: мини-инструмент «Поиск
градуса» (планета, знак, градус°минута′, годы от/до → список дат; тап по
дате → открыть день). Дёшево: один новый модуль движка + маленькая шторка.
