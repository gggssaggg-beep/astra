## 3. Что осталось ЗАПАДНЫМ в ведическом режиме (по важности)

1. **Аспектные секции дня (Луна/Быстрые/Медленные)** — считаются по орбисам.
   В джйотише аспекты (дришти) — по целым знакам, а «содержание дня» — панчанга.
2. **Тексты**: планета-в-знаке/в-доме, мифы знаков, значения аспектов — весь
   корпус западный; управители в джйотише другие.
3. **Курс и тур** — ведического нет (помечено плашкой в настройках).
