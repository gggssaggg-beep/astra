# TASK_STUDY.md — обучалка ПО АСТРОЛОГИИ + контекстная «?» (бриф для Fable)

> Бриф для Fable (архитектор). **Спроектировать реализацию, не писать код.** Fable
> читает: этот файл + `study.md` (общий метод онбординг-тура и проверенные грабли)
> + `CLAUDE.md`. Изучает существующие модули приложения. Выдаёт: план
> `docs/STUDY_IMPL.md` + разбивку на мелкие задачи для дешёвых моделей + PR (код
> не меняет). Правила: оффлайн-первый, «ты», бытовой язык, авторские архетипы богов
> НЕ трогать, «сам элемент, не рамка».

## Цель (слова владелицы)
Человек, который **вообще не разбирается в астрологии**, должен обучиться ей прямо
в приложении. И в любой момент — нажать маленький **«?»** рядом с тем, что видит
на экране, чтобы ещё раз посмотреть те или иные моменты.

## Метод — как в `study.md`, но с двумя добавками
`study.md` даёт проверенный механизм ТУРА по интерфейсу (приветствие 1 раз,
пошаговая подсветка элементов «прожектором», плашка-предложение, перезапуск из
настроек) + грабли (центрирование карточки в пикселях, двойной rAF после смены
вкладки, ширина ряда кнопок, сброс кэша). Всё это переиспользовать.

Но Астре мало «где какая кнопка» — надо ещё **научить самой астрологии** и дать
**повторную справку по запросу**. Поэтому делаем ТРИ слоя:

### Слой 1 — тур по интерфейсу (по `study.md`)
Заполнение блока «ЗАПОЛНИ ПЕРЕД ИСПОЛЬЗОВАНИЕМ» из `study.md` под Астру:
- **Приложение:** Astra — оффлайн «небо по дням» (Vite + Svelte 5 + TS + Capacitor → APK).
- **Стек:** Svelte 5 (руны), TypeScript; попапы/шторки уже есть — `lib/sheet.ts`
  (`use:bottomSheet`), `ui/*Sheet.svelte`; тема/переменные — `app.css`.
- **Разделы для тура (по порядку):** шапка с датой и листанием дня → колесо неба
  (тап по глифу/линии = разбор) → блок Луны/фазы → список планет → аспекты дня →
  «Фигуры дня» → нижнее меню: **Библиотека · Карты · Сообщество · Настройки**.
- Уже есть частичный онбординг — `ui/Welcome.svelte` (первый запуск) и
  `seenJournalHelp`/`seenWelcome` в `models.ts`: **дополнить, не дублировать**
  (правило study.md §«КАК ДЕЛАТЬ»).

### Слой 2 — курс «астрология с нуля» (НОВОЕ)
Структурированный необязательный путь от основ к чтению своей карты. Короткие
уроки, **от простого к сложному** (правило проекта), каждый опирается на живое
колесо и РЕАЛЬНЫЕ позиции дня. Примерная программа (Fable уточнит по имеющимся
текстам):
1. Что такое карта неба: колесо, зодиакальный круг.
2. 12 знаков — стихии и характеры.
3. Планеты и светила — что каждая значит.
4. Дома — что это и зачем.
5. Аспекты — углы, гармоничные/напряжённые.
6. Продвинутое: ретро, узлы Раху/Кету, фигуры, диспозиторы.
7. Собираем вместе — как прочитать свою карту в разделе «Карты».

Требования:
- Пропускаемо (владелица-астролог курс не проходит); вход — из «Помощь и связь»
  в Настройках и из «Библиотеки».
- Прогресс durable (`lib/db.ts` → Preferences): видно пройденное, продолжение с места.
- Урок = тонкая обёртка-подача над УЖЕ написанными текстами + микро-задание
  («найди Солнце на колесе», «какой аспект между …») — тексты НЕ переписывать.

### Слой 3 — контекстная «?» (НОВОЕ, ключевое пожелание)
Маленькая «?» рядом с информацией → тап → краткое объяснение ИМЕННО этого понятия,
кнопка «подробнее» → полная статья в Библиотеке. Доступно всегда, сколько угодно раз.
- Базис уже есть: `ui/InfoSheet.svelte` (тап по символу колеса → разбор
  планеты/знака/аспекта из `lib/lore.ts`). Обобщить в механизм «объясни по ключу».
- Новый `lib/glossary.ts` — короткие объяснения для НОВИЧКА («ты», проще архетипов;
  архетипы остаются для глубины). Один источник правды, ключ = понятие.
- Куда поставить «?» (Fable дополнит): шапка значения (планета·знак·градус);
  карточка аспекта; фаза Луны; значок ретро **℞**; узлы; фигуры дня; дома; куспиды;
  термины Настроек (орбис, система домов).

1. Архитектура трёх слоёв: компоненты тура, курса, поповера «?»; единый экшен/

   `svelte-check` + `npm run build`.
5. Этапность: что малой кровью сразу, что позже.
