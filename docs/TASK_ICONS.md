## Зачем

разная толщина, отсутствующие символы). Цель — **единый набор кастомных SVG** в
эстетике приложения («живое стекло» / neon-stardust), одинаковый на всех
устройствах.

## Подход (когда возьмёмся)
- Все иконки — **SVG** (Claude растр не генерит; vision — только на ввод).
  Единый визуальный язык: толщина линий, скругления, вьюбокс (напр. 24×24),
  `currentColor` для темизации (5 цвето-стилей знаков уже есть — учесть).
- Приоритет по пользе: (1) **планетные/аспектные глифы** (главный источник
  «кривоты» на Android) → SVG-компонент вместо `.glyph`-шрифта; (2) иконки
  нижнего меню и разделов Библиотеки; (3) остальное.
- Хранить как пути (как `SIGN_PATHS`) или маленькие `.svelte`-иконки-компоненты;
  не тянуть тяжёлые растры, не плодить зависимости. Один компонент `<Icon name>`
  поверх словаря путей — самый чистый вариант (заменить и эмодзи, и `.glyph`).
- Партиями (по 5–8 иконок), svelte-check+build после каждой, скриншот-сверка на
  реальном фоне (пайплайн есть). Тема/эстетика — согласовать с владелицей до
  массовой отрисовки (1–2 пробных иконки на утверждение).

## Ресурсы для иконок в Claude Code (запомнить — от владелицы 2026-07-11)
Claude сам рисует иконки в **SVG** (не растр). Способы:
- **Скиллы** (класть в `~/.claude/skills/`, активируются по запросу):
  - `icon-finder` — поиск готовых в 6 библиотеках (Lucide, Heroicons, Phosphor,
    Tabler, Remix, Bootstrap) через Iconify API; отдаёт SVG/React/Vue. Самый
    простой — мгновенный доступ к тысячам готовых.
  - `svg-logo-designer` — уникальный дизайн логотипов/иконок (30–75 SVG за проект,
    психология цвета).
  - `icon-design` — подобрать метафору иконки для абстрактного понятия.
  - `cc-nano-banana` — генерация через Gemini CLI (нужен Google API-ключ).
  - `website-designer-agent` — иконки/фоны/иллюстрации/баннеры.
- **MCP-серверы:**
  - `@benjaminholderbein/mcp-server-svg` — «увидеть» SVG в терминале (рендер в
    PNG), убирает цикл SVG→браузер→терминал. Подключение:
    `claude mcp add svg npx -- -y @benjaminholderbein/mcp-server-svg`.
  - `@mcpware/logoloom` — полный бренд-кит: читает код/бренд, 6–8 SVG-концепций,
    текст→пути, оптимизация, экспорт (PNG/ICO/WebP/OG).
  - `nucleo-mcp` — локальная библиотека Nucleo (поиск/предпросмотр/PDF).
  - `icon-composer-mcp` — иконки Apple `.icon` (Liquid Glass) — нам не нужно
    (Android).
- **Внешнее:** Claude Design (Anthropic Labs), бесплатные SVG-библиотеки
  (LobeHub, UXWing), Font Awesome.
- **Вручную:** попросить Claude написать SVG-код и итеративно доработать.

Рекомендация из справки: начать со скилла **`icon-finder`** (готовые из
популярных библиотек) + при редактировании подключить MCP `mcp-server-svg`
(видеть SVG в терминале). Для уникального стиля — `svg-logo-designer`/`logoloom`.
