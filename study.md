## ЗАДАЧА

Добавь в приложение понятную обучалку по каждому пункту интерфейса. Образец подхода —
приложение `C:\purba\MENS` (`src/screens/OnboardingScreen.tsx` — приветствие первого запуска;
`src/ui/coach.tsx` — подсказки-«пузырьки» над элементами, показываются один раз, сбрасываются
из настроек). Изучи их перед началом, если папка доступна.

Сделай четыре связанных части:

### 1. Приветствие при первом открытии
- Показывается ОДИН раз (флаг в localStorage / AsyncStorage, напр. ключ `welcomeSeen`).
- Как первый экран телефонного приложения: 3–4 пункта вида «эмодзи + короткий заголовок + 1–2 строки».
  Пункты: что это за приложение, из чего состоит, ключевая фича/режимы, приватность данных.
- Две кнопки: **«🎓 Пройти обучение»** (запускает тур) и **«Начать без обучения»** (просто закрыть).
- Именно сюда встрой предложение пройти обучение.

### 2. Пошаговый тур по каждому пункту (главное)
- Массив шагов `TOUR_STEPS`. Каждый шаг: `sel` (что подсветить), опц. `tab`/`view` (куда переключиться,
  чтобы показать раздел живьём), `place` ('top'|'bottom'|'center'), `color` (акцент), `title`, `text`.
- По одному шагу на КАЖДЫЙ значимый пункт из списка выше + короткий интро-шаг и финал-шаг.
- Механика подсветки: полупрозрачное затемнение всего экрана + «дырка» вокруг текущего элемента
  (в вебе — приём `box-shadow: 0 0 0 9999px rgba(…)` на прозрачном блоке-«прожекторе»).
- Поверх — карточка-подсказка рядом с элементом с кнопками: **✕ (закрыть)**, **Назад**, **Далее**
  (на последнем шаге «Далее» → «Готово»). Счётчик «Шаг N / M».
- Тур блокирует случайные клики по интерфейсу (прозрачный слой-перехватчик), пользователь идёт по кнопкам.
- В конце вернуть исходную вкладку/экран и позицию прокрутки.
- Закрытие по Esc и по ✕/Пропустить. Пропущенные (не найденные) элементы — тихо скипать.

### 3. Предложение обучения при КАЖДОМ открытии
- Тонкая ненавязчивая плашка (тост/баннер) над нижней панелью: «Не знаете, с чего начать?
  Пройдите короткое обучение» + кнопка «Начать» + ✕.
- Показывать при каждом запуске, КРОМЕ самого первого (там уже приветствие).
- Легко закрывается, сама исчезает через ~12 сек. Не показывать, если тур уже идёт.

### 4. Точки повторного запуска
- Раздел «Обучение» в настройках с кнопкой «🎓 Пройти обучение заново».
- (Для веба) deep-link: `…/#tour` запускает тур сразу, `…/#tourN` — с шага N (удобно для теста и ссылок из бота).

## ВАЖНЫЕ НЮАНСЫ (грабли, уже проверено на практике)

- **Центрирование карточки-подсказки** для шагов «по центру» делай в пикселях
  (`left = (innerWidth - width)/2`), а НЕ через `transform: translate(-50%,-50%)` — CSS-анимация
  появления перебивает `transform`, и карточку уводит вбок / обрезает кнопку.
- **Ширина ряда кнопок**: на узкой карточке (~320px) три кнопки в ряд не влезают и переполняют её.
  Реши: «Пропустить» вынеси в ✕ в углу карточки, в ряду оставь только Назад + Далее.
- **Позиционируй после перерисовки**: если шаг переключает вкладку, измеряй элемент через
  двойной `requestAnimationFrame`, иначе поймаешь старые координаты.
- **Плашка «при открытии» не должна перекрывать плавающие кнопки** (музыка/настройки и т.п.) —
  подними её выше них (`bottom` с запасом), учти `env(safe-area-inset-bottom)`.
- **Переключение вкладок внутри тура** делай облегчённой функцией без записи в историю «Назад»,
  чтобы тур не плодил кнопку возврата.
- **Сброс кэша (для PWA/веба)**: после правок ОБЯЗАТЕЛЬНО бампни версию service worker (имя CACHE)
  и все `?v=` у app.js/style.css/sw.js, и константы APP_VER. Иначе телефоны не увидят обновление.
- **Проверка headless-скриншотом (Edge/Chrome)**: страница с `<meta viewport maximum-scale=1>`
  верстается ШИРЕ, чем захватывается PNG (при `--window-size=390` реальный `innerWidth≈504`).
  Для достоверных скриншотов бери окно ≥600px (там `innerWidth ≈ window − 30`). Это не баг вёрстки.

## ГОТОВО, КОГДА

- Приветствие показывается один раз и содержит кнопку «Пройти обучение».
- Тур проходит по всем пунктам из списка, подсвечивает элементы, переключает разделы, корректно
  позиционируется, ничего не обрезано, закрывается по ✕/Esc/Готово.
- Плашка-предложение появляется при каждом открытии (кроме первого) и легко закрывается.
- Обучение перезапускается из настроек.
- Стиль совпадает с приложением. Синтаксис проходит проверку. Версии/кэш забамплены (если это веб/PWA).
- Покажи 3–5 скриншотов ключевых экранов (приветствие, интро тура, подсветка элемента,
  переключение вкладки, плашка).
