## 1. Слой 3 — контекстная «?» (глоссарий)

### 1.1 Модель: `lib/glossary.ts`

Один источник правды «понятие → короткое объяснение новичку». Тексты — НОВЫЕ
(проще архетипов, 2–4 предложения, «ты»), но «подробнее» ведёт к УЖЕ написанным
текстам — ничего не дублируем.

```ts
/** Куда ведёт «подробнее»: либо навигация в существующую шторку,
 *  либо готовый длинный текст из существующего lore-модуля (раскрыть на месте). */
export type GlossMore =
  | { kind: 'sheet'; target: GlossSheet; label: string }   // «Открыть в Библиотеке»
  | { kind: 'text'; label: string; text: () => string };   // раскрыть существующий текст

/** Мишени навигации = уже существующие шторки App.svelte (ничего нового). */
export type GlossSheet =
  | 'library' | 'interpretations' | 'houses' | 'archetypes' | 'signMyths'
  | 'retro' | 'figures' | 'dispositors' | 'planetCusps' | 'degree'
  | 'charts' | 'chartsSynastry' | 'settings' | 'course';

export interface GlossEntry {
  title: string;    // «Орбис»
  short: string;    // 2–4 предложения новичку, «ты», бытовой язык
  more?: GlossMore; // опционально — не у каждого термина есть «глубина»
}

export const GLOSSARY: Record<string, GlossEntry> = { /* ключи — §1.4 */ };
export const gloss = (key: string): GlossEntry | null => GLOSSARY[key] ?? null;
```

Вариант `kind: 'text'` тянет готовые тексты лениво (`() => string`), например
`() => ASPECT_LORE['трин'].text` или `() => PHASE_MEANING['retro']` — переиспользование
без копипасты. Никаких импортов тяжёлых модулей на верхнем уровне не нужно —
все lore-модули лёгкие (строки).

### 1.2 UI: `ui/Hint.svelte` + `ui/GlossarySheet.svelte`

**`Hint.svelte`** — сама «?». Крошечный круглый бейдж (примерно 16×16 визуально,
хит-зона ≥ 28px через padding), цвет `var(--ink-faint)`, при тапе — hапtика
`tick()` и открытие глоссария:

```svelte
<script lang="ts">
  import { openGloss } from '../lib/glossaryStore.svelte.ts';
  import { tick } from '../lib/haptics.ts';
  let { k }: { k: string } = $props();
</script>
<button class="hint-q" aria-label="Что это?"
  onclick={(e) => { e.stopPropagation(); tick(); openGloss(k); }}>?</button>
```

`e.stopPropagation()` ОБЯЗАТЕЛЕН: «?» стоит внутри кликабельных карточек
(AspectCard открывает трактовку по клику на карточку) — тап по «?» не должен
проваливаться в родителя. Правило проекта «сам элемент, не рамка»: подсветки
и GlowCard вокруг «?» не делаем; системный tap-highlight уже погашен глобально.

**`lib/glossaryStore.svelte.ts`** — модуль-стор (Svelte 5 руны в `.svelte.ts`),
чтобы НЕ протаскивать колбэки через 10 компонентов:

```ts
export const glossState = $state<{ key: string | null }>({ key: null });
export const openGloss = (key: string) => { glossState.key = key; };
export const closeGloss = () => { glossState.key = null; };
```

**`GlossarySheet.svelte`** — нижняя шторка по образцу `InfoSheet.svelte`
(тот же `use:bottomSheet`, тот же стиль header/role/text), но:
- z-index **32/33** (бэкдроп/лист) — ВЫШЕ InfoSheet (26/27) и шторок Библиотеки
  (20/21): «?» открывается ПОВЕРХ любой шторки. `pushScrollLock` в `bottomSheet`
  считает вложенность сам — ничего не менять.
- Контент: `title` + `short`; если `more.kind === 'text'` — кнопка-аккордеон
  «{label}» раскрывает длинный текст на месте; если `kind === 'sheet'` — кнопка
  «{label} →», которая закрывает глоссарий и просит App открыть шторку.

**Монтирование в `App.svelte`** (один раз, в конце разметки):

```svelte
{#if glossState.key}
  <GlossarySheet key={glossState.key} onclose={closeGloss} onnavigate={openGlossTarget} />
{/if}
```

`openGlossTarget(target: GlossSheet)` — маленькая функция в App: закрыть глоссарий
и выставить соответствующий `showX = true` (все флаги уже есть; `chartsSynastry`
→ `showCharts = { mode: 'synastry' }`; `settings` → `showData = true`; `course` —
появится в слое 2, до того ключей с этой мишенью не заводить).

**Кнопка «Назад» (Android)**: в `App.onBack()` ПЕРВОЙ строкой добавить
`if (glossState.key) { closeGloss(); return; }` — глоссарий самый верхний слой.

## 2. Слой 1 — тур по интерфейсу (механика `study.md`)

### 2.1 Компоненты

**`lib/tour.ts`** — данные шагов, без DOM:

  place: 'top' | 'bottom' | 'center';

**`ui/Tour.svelte`** — прожектор + карточка. Механика ровно по `study.md`:
- Затемнение: прозрачный блок-«прожектор» над элементом с
  `box-shadow: 0 0 0 9999px rgba(5,7,20,.72)` + `border-radius` под элемент.
- Прозрачный слой-перехватчик кликов на весь экран (тур ведут кнопки).
- Карточка-подсказка: кнопки **✕** (в углу), **Назад**, **Далее** (на последнем —
  «Готово»), счётчик «Шаг N / M». В ряду ТОЛЬКО Назад+Далее (грабля ширины).
- Esc закрывает (`svelte:window onkeydown`); аппаратный «Назад» — App.onBack
  добавляет `if (tourOpen) { closeTour(); return; }` (выше глоссария).
- Позиционирование карточки для `place:'center'` — В ПИКСЕЛЯХ
  (`left = (innerWidth - w)/2`), НЕ `translate(-50%,-50%)` (грабля: CSS-анимация
  появления перебивает transform).
- Перед замером шага: `el.scrollIntoView({ block:'center' })` + **двойной
  `requestAnimationFrame`** — грабля устаревших координат.
- Элемент не найден (нет фигур в этот день и т.п.) — шаг ТИХО пропускается.
- В конце — `window.scrollTo({ top: 0 })` (вернуть исходную позицию).
- z-index 45 (выше всех шторок 20–33, ниже Welcome 40 не нужно — тур стартует
  ПОСЛЕ закрытия Welcome).
- Состояние `tourOpen` — в том же `glossaryStore.svelte.ts` (переименовать в
  `lib/studyStore.svelte.ts`: глоссарий + тур + курс в одном мини-сторе).

Тур НЕ открывает шторки (в отличие от study.md с вкладками): все шаги — на
экране дня и таббаре, «что внутри» рассказывает текст шага. Это убирает целый
класс граблей с переключением вкладок и историей «Назад». Единственная прокрутка —
вертикальная лента дня.

## 3. Слой 2 — курс «астрология с нуля»

### 3.1 Модель: `lib/course.ts`

```ts
export interface LessonBlock {
  text?: string;                    // короткая подача (2–5 предложений, «ты»)
  glossKeys?: string[];             // чипы «?»-терминов урока (тап = GlossarySheet)
  loreRef?: { label: string; text: () => string }; // готовый текст из lore-модуля (аккордеон)
  go?: { label: string; target: GlossSheet };      // «Открой сам» — навигация
}
export interface LessonQuiz {
  // вопрос по ЖИВЫМ данным дня строит функция: получает positions/aspects,
  // возвращает вопрос + варианты + индекс верного. Оффлайн, движок уже в App.
  build: (ctx: { positions: BodyPosition[]; aspects: AspectRecord[] }) => {
    q: string; options: string[]; correct: number } | null;   // null = нет данных, квиз скрыть
}
export interface Lesson {
  id: string; emoji: string; title: string; intro: string;
  blocks: LessonBlock[]; quiz?: LessonQuiz;
}
export const COURSE: Lesson[] = [ /* §3.2 */ ];
```

Урок = «тонкая обёртка-подача»: свои — только короткие связки-подводки; вся
глубина — `loreRef` на существующие тексты и `glossKeys` на глоссарий. Прогресс:
`studyDone` в Settings (durable через существующий механизм db).

### 3.2 Программа курса (8 уроков, от простого к сложному)

| # | id | Урок | Опирается на (переиспользование) | Микро-задание (quiz) |

### 3.3 UI

**`CourseSheet.svelte`** — список уроков в стиле LibrarySheet (те же `.row` +
GlowCard): эмодзи, название, галочка ✓ у пройденных, у первого непройденного —
чип «продолжить». z-index 20/21 (обычная шторка).

**`LessonSheet.svelte`** — сам урок: intro → blocks (текст / чипы-«?» /
аккордеоны loreRef / кнопка go) → quiz (варианты-кнопки, верный подсвечивается,

**Интеграция App.svelte**: `showCourse`, `showLesson: string | false` + пункт в
LibrarySheet «🎓 Астрология с нуля» (первым рядом, над Журналом — витрина для
новичка; из Библиотеки ничего не удаляем) + кнопка в DataPanel + ветки в

**Данные для квизов**: LessonSheet получает пропы `{ engine, date, tz, objects, orbOf }`
(как DayScreen) и берёт `positions`/`aspectsOnCached` из `lib/dayCache.ts` — кэш
общий, WASM не пересчитывается.

⚠ Реактивность: любые `db.x.all()` в курсах — через `.slice()` (правило Svelte 5).

## 4. Разбивка на задачи для дешёвых моделей

Правила КАЖДОГО запуска исполнителя (вставлять в промпт):
- Партия — МАЛЕНЬКАЯ (3–4 текста / 1–2 компонента). Коммит после каждой партии.
- Проверка перед коммитом: `npx svelte-check` (0 ошибок 0 предупреждений) и
  `npm run build` в `app/`. Существующие тесты не трогать и не ломать

- Новые шторки — копия паттерна существующих: `use:bottomSheet={{ onclose }}`,

## 5. Риски и грабли (сводка для исполнителя)

- **z-index лестница**: шторки 20/21 → InfoSheet 26/27 → Glossary 32/33 → Welcome 40
  → Tour 45. Не выше Starfield? Starfield — фон, не мешает.
- **`use:bottomSheet`** сам считает вложенность scroll-lock — НЕ городить свой.
- **`e.stopPropagation()`** на «?» внутри кликабельных карточек — иначе двойное открытие.
- **Двойной rAF + scrollIntoView** перед замером шага тура; пиксельное центрирование.
- **Тур не открывает шторок** — только подсвечивает и рассказывает (осознанное упрощение).
- **`.reveal` без `use:reveal` = вечно невидим** (прецедент ChartFigureCard).
- **`db.x.all().slice()`** в компонентах (Svelte 5 реактивность).
- **Settings-поля только опциональные** — мердж с дефолтами, миграций не нужно.
- **OTA**: всё — веб-код, уедет живым обновлением; APK не требуется; версии
  штампуются CI автоматически, руками не бампить.
- **Кэш дня общий** (`lib/dayCache.ts`) — квизы берут из него, не дёргают WASM заново.
- **Тексты**: новые — только short-глоссарий, связки уроков и шаги тура; всё
  длинное — ссылками на существующие модули. Авторские раскладки не «чинить».
