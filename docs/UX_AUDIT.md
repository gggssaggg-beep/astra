# UX_AUDIT.md — аудит интерфейса на избыточность (2026-07-09)

> Ответ на бриф `docs/TASK_UX_AUDIT.md`. Исследование Fable: **код в этом PR не
> менялся**, документ — таблица находок + пошаговое задание для дешёвых моделей
> (Sonnet/Haiku). Правила, которые аудит уважает: астрологические возможности НЕ
> вырезать; сомнение → прогрессивное раскрытие; «сам элемент, не рамка»;
> оффлайн-первый; интерфейс на «ты».

## Резюме (полстраницы)

Приложение после раундов 7–29 в целом **опрятнее, чем ожидалось**: настройки уже
свёрнуты в аккордеон, архетипы/справочники — единый паттерн «аккордеон-строка»,
выделение — единый GlowCard/линия. Главные оставшиеся очаги избыточности:

1. **Библиотека — плоский список из 13 пунктов** без групп: глазами не
   сканируется, похожие разделы (4 справочника «планета×что-то») не собраны.
2. **Экран открытой карты в «Картах» — самый длинный скролл приложения**:
   колесо + 2 кнопки ИИ + фигуры + цепочки + 2 раздела куспидов + списки
   аспектов + прогноз + позиции/дома — всё развёрнуто одновременно.
3. **Шторка аспекта — три полноразмерные кнопки-действия подряд** («Обсудить с
   Claude», «Промпт для любой ИИ», «Обсуждения сообщества») отжимают трактовку
   и заметку вниз; та же тройка повторена в 3 местах кода.
4. **Точечные дубли кнопок**: «Закрыть» в футере календаря (при живых ✕, бэкдропе,
   свайпе и «Назад»), «← Назад» в футере формы человека (при ← в шапке).
5. **Техническая избыточность**: каждая из ~24 шторок несёт собственную копию
   CSS `.backdrop/.sheet/@keyframes up/header/.x`; две шторки трактовки аспекта
   (`InterpretationSheet` / `StaticInterpretationSheet`) — близнецы на ~85%;
   в `App.svelte` 14 булевых флагов библиотечных шторок и лестница `onBack` на
   40 строк. Пользователь этого не видит, но каждая правка делается дважды.

Ничего «мёртвого» не найдено: законсервированный композит в движке — осознанное
решение (в UI его нет), все входы Библиотеки ведут в живые разделы.

## 3. Пошаговое задание для дешёвых моделей

Общие правила каждой партии:
- **Не менять** тексты трактовок/архетипов, движок (`app/src/engine/`), расчёты,
  порядок аспектов, правило «сам элемент, не рамка», офлайн-логику.
- После партии: `npx svelte-check` (0 ошибок / 0 предупреждений сверх текущих) и
  `npm run build` в `app/` — зелёные.
- Критерий приёмки партии: **ни одна функция не потеряна** (все кнопки/разделы
  достижимы ≤ +1 тап), экран стал спокойнее (меньше элементов видно сразу).
